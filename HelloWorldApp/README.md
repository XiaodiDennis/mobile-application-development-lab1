## Objective
Create and run a basic "Hello World" mobile application using Xcode, the iOS SDK, the iOS Simulator, and (where available) a physical iPhone.

## Run
1. Open `HelloWorldApp.xcodeproj` in Xcode.
2. Select an available iPhone Simulator and press Run (`Cmd+R`).
3. For a physical iPhone, connect it, trust the Mac, select your Apple ID team under **Signing & Capabilities**, choose the iPhone as the destination, then Run.

## Expected output
The screen displays:
- `Hello World!`
- `Mobile Application Development - Laboratory Work 1`
- `Xiaodi Wang · KP-44i`
